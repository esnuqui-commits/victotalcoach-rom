# 🤾 Handball Coach - Versiunea Română

Aceasta este o aplicație de gestionare a antrenamentelor de handbal, concepută pentru planificare, evaluare a jucătorilor și scouting video.

## 🚀 Caracteristici principale
- **Planificare:** Organizarea microciclurilor și a sesiunilor de antrenament.
- **Gestionarea Loturilor:** Controlul jucătorilor și al pozițiilor.
- **Banca de Exerciții:** Bibliotecă personalizabilă de exerciții cu suport multimedia.
- **Scouting Video:** Analiza meciurilor cu marcaje de secțiuni și butonieră de acțiuni.
- **Controlul Sarcinii:** Monitorizarea intensității antrenamentelor.

## 🛠️ Instalare și Utilizare
Deoarece această aplicație utilizează `localStorage` și `IndexedDB` pentru a salva datele direct în browserul dumneavoastră:
1. Deschideți `index.html` în orice browser modern (recomandat: **Brave** sau **Chrome**).
2. Datele sunt salvate local pe dispozitivul dumneavoastră.
3. Pentru backup, utilizați funcția de "Copie de rezervă" din meniul aplicației.

## 🌐 Desploiere pe GitHub Pages
Pentru a accesa această aplicație printr-un link web:
1. Creați un nou repository pe GitHub.
2. Încărcați fișierele din acest folder.
3. Mergeți la **Settings** $\rightarrow$ **Pages**.
4. Selectați ramura `main` și salvați. 
5. Veți primi un link de tipul `https://utilizator.github.io/repository-name/`.
